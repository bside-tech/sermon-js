Six new presets: `postgres.ping` (any PostgreSQL driver), `vercel.aiGateway` (credit balance), `vercel.blob`, `meilisearch` (health, index and document count), `resend` (domains) and `elevenlabs` (credits used this period). Keys that are valid but scoped (a sending-only Resend key, an ElevenLabs key without the user scope, a Meilisearch key that can't read statistics) count as working.
